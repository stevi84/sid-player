# C64 Pro Mono
- from https://style64.org/release/c64-truetype-v1.2.1-style
- Modified using (FontForge)[https://fontforge.org/en-US/]
- Added glyphs for code-points 1fb70, 1fb71, 1fb72, 1fb74, 1fb75, 1fb76, 1fb77, 1fb78, 1fb7a, 1fb7b, 1fb7c, 1fb7d, 1fb7e, 1fb82, 1fb83, 1fb87, 1fb88, 1fb8c, 1fb8f (Symbols for Legacy Computing)
- see (SidParse.ts)[../src/SidParse.ts]
- Advantage: Code is readable using Cascadia Code font, as the glyphs at these code-points are at least very similar to the original ones.
